# UI Flow Documentation

## Authentication Flow
Login Page -> JWT Auth -> Dashboard (or redirect to requested page)

## POS Flow
Select Table -> Add Products to Cart -> Place Order -> KDS receives order -> Kitchen prepares -> Order Ready -> Payment -> Receipt

## Self-Order Flow
Scan QR Code -> Browse Menu -> Add to Cart -> Place Order -> Order sent to KDS

## Kitchen Display Flow
New orders appear automatically -> Staff taps "Start" -> Prepares -> Taps "Ready" -> Waiter serves

## Payment Flow
Select order -> Choose payment method (Cash/Card/UPI/QR) -> Enter amount -> Complete payment -> Receipt generated
