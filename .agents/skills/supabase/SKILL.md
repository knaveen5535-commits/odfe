# Supabase Skill

This skill provides guidance for using Supabase with the ODFE Cafe POS system. Supabase can be used for optional authentication, real-time subscriptions, and storage.

## Features
- Authentication (email/password, OAuth)
- Real-time subscriptions for order updates
- Storage for product images
- Edge Functions for serverless logic

## Usage
Set `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY` in `.env` to enable Supabase features.
